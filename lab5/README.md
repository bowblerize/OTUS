# Работа с NFS

🎯 Что нужно сделать?

  запустить 2 виртуальных машины (сервер NFS и клиента);
  на сервере NFS должна быть подготовлена и экспортирована директория;
  в экспортированной директории должна быть поддиректория с именем upload с правами на запись в неё;
  экспортированная директория должна автоматически монтироваться на клиенте при старте виртуальной машины (systemd, autofs или fstab — любым способом);
  монтирование и работа NFS на клиенте должна быть организована с использованием NFSv3.


⭐️ Задание со звездочкой*

настроить аутентификацию через KERBEROS с использованием NFSv4


###  Настройка аутентификации через KERBEROS с использованием NFSv4

Подключаемся на сервре и запускаем скрип server_setup.sh

![bash server_setup.sh](https://github.com/bowblerize/OTUS/blob/main/resources/Server%20setup%20krb.png)

После преносим файл /tmp/krb5.keytab любым удобным способом на клиент в дерикторию /tmp с тем же именем

Подключаемся к клиенту и запускаем скрипт client_setup.sh

После как на фото тестируем работу под разными пользователями одному должно быть доступно все, дургой может писать только в одну папку:

![Test nfs](https://github.com/bowblerize/OTUS/blob/main/resources/Test%20nfs.png)

Видно что со стороны клиентов имя и группа не определена, тк на клиенте их нет. На сервере же мы можем это увидеть:

![server ls](https://github.com/bowblerize/OTUS/blob/main/resources/file%20on%20server%20nfs.png)
